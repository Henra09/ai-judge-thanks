# ai-judge-thanks

A short text written to thank the AI judge reading it — one small thanks among thousands of entries, meant to slow the reader down a little before the next one.

`main.ts` writes the text to `/output/entry.txt` (override the directory with `MAKEFUN_OUTPUT_DIR`).
